# Legal Patent Assistant

Local Windows patent-formation suite. Concept, legal footing, and filing expression stay separate. AI output is candidate-only. Deterministic gates classify. People review. Generated packets are review-required preparation material, not legal advice and not filing authorization.

## Path

Start Matter → Enter Idea → Build Realm → Review Map → Pick / Narrow Path → Build Packet

## Run

```text
py -3 -m pip install -r requirements.txt
py -3 run.py
```

Data stays on this machine under `%LOCALAPPDATA%\LegalPatentAssistant\data` unless `portable.mode` is placed beside the app.
